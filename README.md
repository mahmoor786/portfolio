# Mahmoor, portfolio

Personal portfolio for winning website and app projects. Plain HTML, CSS and JavaScript with no build step, made for GitHub Pages.

- `index.html`: the full site (work, how it works, prices with USD/GBP/EUR switch, project brief form, questions, contact)
- `work.html`: work-only page for Fiverr and Upwork profiles (no prices, no contact details)
- `assets/js/site.js`: content, prices and the brief form
- `assets/js/screens.js`: the concept project screens, drawn in HTML
- `PRODUCT.md`: the product brief the design follows

## Before going live

1. In `assets/js/site.js`, set `WHATSAPP` (digits only, with country code) and `EMAIL`.
2. Replace `hello@mahmoor.dev` in `index.html` with your email, and fill in the LinkedIn and Instagram links.
3. Swap concept projects for real client work as it comes in.

## Publish on GitHub Pages

Free GitHub accounts can only serve Pages from public repositories.

1. Make the repository public (Settings, General, Danger zone).
2. Optional: rename it to `mahmoor786.github.io` so the site lives at `https://mahmoor786.github.io`.
3. Settings, Pages: Source "Deploy from a branch", branch `main`, folder `/ (root)`.
