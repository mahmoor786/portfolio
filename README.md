# Mahmoor Ullah — portfolio

Portfolio website for Mahmoor Ullah, freelance web designer and developer. Built with Astro, Three.js and GSAP, hosted on GitHub Pages.

## Run it

```
npm install
npm run dev      # preview at http://localhost:4321/portfolio/
npm run build    # build into dist/
```

## Change the content

Everything you can edit (name, contact details, services, prices, projects, and switches to show or hide sections) is in `src/data/site.ts`.

## Publish a blog post

Add a Markdown file to `src/content/blog/`. Copy an existing post for the format. It goes live when the change reaches `main`.
